# Invoker Voice

Голосовое управление Инвокером в Dota 2. Говорите название заклинания, и программа сама
нажимает сферы и Invoke. Говорите номер башни, и камера переезжает к ней.

Распознавание речи работает офлайн, на [Vosk](https://alphacephei.com/vosk/).

## Что нужно

- Windows 10/11
- [Python 3.10 или новее](https://www.python.org/downloads/). При установке отметьте **Add python.exe to PATH**.
- Микрофон, выбранный в Windows по умолчанию

## Запуск

1. Скачайте репозиторий (**Code → Download ZIP**) и распакуйте.
2. Запустите `start.bat`. При первом запуске он поставит библиотеки и скачает модель
   распознавания (45 МБ).
3. Программа спросит, на каких клавишах у вас сферы, Invoke и слот D. Нажимайте
   свои клавиши, Enter оставляет значение как есть. Выбор запоминается в `keys.json`.
   При следующих запусках достаточно нажать Enter.
4. Перезапустите Dota, чтобы подхватился бинд камеры (см. ниже).

## Как пользоваться

Программа слушает, **только пока включён Caps Lock**. Если Caps выключен, она вас не слышит.
Клавиши нажимаются, только когда активно окно Dota 2.

### Заклинания

| Заклинание | Сферы | Слова |
|---|---|---|
| Cold Snap | QQQ | холод, мороз, колд, заморозка, фриз |
| Ghost Walk | QQW | призрак, невидимость, гост, невидимка (применяется сразу) |
| Ice Wall | QQE | стена, лёд, айс, стенка, барьер |
| EMP | WWW | импульс, мана, эмп |
| Tornado | WWQ | торнадо, смерч, вихрь, ураган, циклон, буря, ветер, ветра |
| Alacrity | WWE | ускорение, скорость, бафф |
| Sun Strike | EEE | солнце, луч, сан страйк |
| Forge Spirit | EEQ | духи, спирит, демоны |
| Chaos Meteor | EEW | метеор, метеорит, комета, метеоры, хаос метеор, кинь метеор |
| Deafening Blast | QWE | волна, бласт |

Заклинание встаёт в слот D, применяете его сами. Ghost Walk применяется сразу.
Команды можно говорить подряд: «торнадо метеор».

### Камера

Говорите номер числом: «семь», «тринадцать».

| Номер | Свет | Номер | Тьма |
|---|---|---|---|
| 1 / 2 / 3 | T1 / T2 / T3 топ | 10 / 11 / 12 | T1 / T2 / T3 топ |
| 4 / 5 / 6 | T1 / T2 / T3 мид | 13 / 14 / 15 | T1 / T2 / T3 мид |
| 7 / 8 / 9 | T1 / T2 / T3 бот | 16 / 17 / 18 | T1 / T2 / T3 бот |

Ещё есть фразы «трон света» / «трон тьмы», «фонтан света» / «фонтан тьмы»,
«логово верх» / «логово низ» (Рошан).

Как это работает: программа сама находит Dota через Steam и дописывает в
`game/dota/cfg/autoexec.cfg` строку `bind "KP_MULTIPLY" "exec voice_camera"`. При команде
она записывает в `voice_camera.cfg` строку `dota_camera_set_lookatpos X Y` и нажимает
**Num \***. Не занимайте эту клавишу в Dota.

Если камера не двигается:
- введите в консоли Dota `exec autoexec`;
- или добавьте в параметры запуска Dota в Steam `+exec autoexec`.

## Настройки

Настройки задаются в начале `invoker_voice.py`:

- `MIC_NAME`: часть названия микрофона, если нужен не тот, что выбран по умолчанию.
- `FAST_TRIGGER`: через сколько секунд срабатывает команда, по умолчанию 0.25. Если
  «пятнадцать» срабатывает как «пять», увеличьте значение.
- `MIN_CONFIDENCE`: насколько уверенно должно быть распознано слово.
- `SPELLS`: слова для заклинаний. Годятся только обычные русские слова из словаря модели.
